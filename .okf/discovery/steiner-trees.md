# Steiner trees

Imagine drawing paths between three pins on a map with as little ink as possible. A Steiner tree can introduce a junction you didn’t ask for if sharing that junction shortens the whole drawing.

## Houseplants example

Suppose an agent found Orchid, Underwatering, and Watering Workflow in a search. Soil Moisture Check explains how those pages fit together. The shared map takes four links. The two ordinary shortest paths in the prototype take six. In two other houseplant examples, both approaches used the same number of links. A compact map can still pick a generic junction, so the reader or agent needs the supporting links.

The example follows links either way. [Personalized PageRank](./pagerank.md) starts from a concept and selects what else to explore.
