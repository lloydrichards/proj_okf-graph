# Combining links, frontmatter, and folders

These notes show what changes when an analysis uses more than one kind of OKF evidence. The first three experiments use the houseplants snapshot. The final note separates open research questions from measured results.

- [Three kinds of evidence](./evidence-layers.md) — Distinguish author-written links, page attributes, file locations, and index entries.
- [PageRank with metadata](./metadata-guided-ranking.md) — Compare topic-guided restarts, type filters, and folder filters.
- [Shared requirements and different needs](./shared-requirements.md) — Use typed links and tags together to compare two plants.
- [Reachability with index navigation](./index-and-concept-routes.md) — Compare the route from a symptom with the route through the bundle index.
- [Questions that need more than one method](./combined-methods.md) — Pair methods that answer different parts of a research question.
- [Symlinks as alternate concept placements](./symlink-placement.md) — Test whether the same file can appear in multiple folders without changing its graph identity.
