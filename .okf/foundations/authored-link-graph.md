# Authored link graph

Each concept page is a point on the map. If page A contains a link to page B, draw A → B. A backlink view lets you travel in reverse. The authored arrow still points from A to B.

Analyses choose which arrows to include. [Strongly connected components](../routes/strongly-connected-components.md) respect the original direction. [Effective resistance](../routes/effective-resistance.md) treats links as two-way in this research. The [houseplants snapshot](./houseplants-snapshot.md) records the counting rules.
