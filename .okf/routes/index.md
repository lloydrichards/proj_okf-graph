# Routes and resilience

What readers can reach, what blocks a route, and which alternatives remain.

## Concepts

- [Dominators](./dominators.md) — Identifies pages every authored route from a chosen entry must pass through.
- [Menger's theorem](./mengers-theorem.md) — Connects the number of independent routes to the smallest set of links that can block them all.
- [Strongly connected components](./strongly-connected-components.md) — Groups pages when any member can reach any other and return along authored arrows.
- [Transitive reduction](./transitive-reduction.md) — Hides shortcuts from an acyclic graph while preserving which destinations are reachable.
- [Effective resistance](./effective-resistance.md) — Measures how much alternate routes can carry when links are treated as equal resistors.
